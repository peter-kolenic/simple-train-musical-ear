Ear Trainer

Listen to a tone. Then find it on the keyboard.

Shortcuts: Space play tone, R replay my guess, Enter or N next. Letter keys answer in the lowest octave. Add Shift for one octave higher.

Settings

MIDI keyboard

Changes apply at once. If the current tone is outside the new range or note set, a new tone plays at once.

Stats

Audio debug

Check by ear: no clicks at note start or end, no distortion when notes overlap, A4 = 440 Hz on a tuner.

MIDI debug

Turn MIDI on, and select the light output and channel in Settings. The buttons send to that output and channel. The log shows the last messages from all inputs, except clock (F8) and Active Sensing (FE).
